{% section "Welcome to AI in Data Science", "welcome-to-ai-in-data-science" %}

AI is changing the way data work gets done.

Data practitioners are already using AI to help write code, clean and organize data, explore patterns, create visualizations, summarize findings, automate tasks, and communicate results. But using AI well takes more than knowing how to prompt a tool. You still need to understand the problem, know what the data mean, check whether AI-generated work is accurate, and decide whether the result makes sense in the real world.

**AI in Data Science: Preparing AI-Enhanced Data Practitioners** is designed to help you build those skills.

Throughout this course, you will use AI as part of realistic data work while strengthening the knowledge and judgment that employers need from data professionals. You will practice deciding when AI can help, when its work needs to be checked or revised, and when human knowledge and decision-making are essential.

{% section "What Is an AI-Enhanced Data Practitioner?", "what-is-an-ai-enhanced-data-practitioner" %}

An **AI-Enhanced Data Practitioner** is someone who combines data skills with AI tools to do data work more effectively.

That might mean using AI to help you:

- understand and explore a dataset;
- write or troubleshoot code;
- clean and prepare data;
- identify patterns;
- create visualizations;
- automate repeatable tasks;
- explain results to different audiences; or
- develop better ways for an organization to use data.

But AI does not take away your responsibility for the work.

You still need to understand the problem, know where the data came from, recognize when something looks wrong, verify results, consider the people affected by the work, and communicate findings responsibly.

The industry-informed profile behind this course emphasizes both sides of the role: using AI to accelerate data work **and** applying human knowledge, organizational understanding, evaluation, communication, and judgment.

{% section "Module 0: Python Readiness", "module-0-python-readiness" %}

Before you begin the main course modules, make sure you have enough Python experience to work comfortably with data and understand basic code.

**Module 0 is not designed to teach programming from the beginning.** Its purpose is to help you build or refresh the Python skills you will need in the rest of the course.

An especially important goal is being able to understand and check code created with AI. AI can generate Python quickly, but you need enough programming knowledge to recognize what the code is doing, test it, troubleshoot problems, and decide whether the output makes sense.

By the end of Module 0, you should be able to:

- Set up and use a Python environment such as Google Colab or Jupyter Notebooks.
- Work with basic Python variables, data types, lists, functions, loops, conditionals, dictionaries, and program logic.
- Load and work with data using pandas.
- Filter, clean, sort, group, and summarize data.
- Understand basic structures such as data frames and data types.
- Write, run, and debug basic Python code.
- Look at AI-generated Python code and decide whether the code and its output are appropriate for the task.

If you need more preparation, your instructor may ask you to complete selected lessons from resources such as:

- **Introduction to Python**
- **Intermediate Python**
- **Data Manipulation with pandas**

You may not need every lesson. The goal is simply to make sure you have the skills you need to work successfully with the course activities.

{% section "Module 1: The AI-Enhanced Data Practitioner", "module-1-the-ai-enhanced-data-practitioner" %}

AI can now complete many technical tasks that once took data practitioners a great deal of time. That changes where your own skills and attention become most important.

In this module, you will explore how AI is changing data work and what that means for you as a future data professional. You will see how AI can speed up tasks such as coding and analysis while also creating new risks. You will examine why organizational and user context matters, how AI-generated work can fail, and why you still need to verify results before they are used to make decisions.

You will finish the module by practicing a **Human-in-the-Loop Decision Lab**, where you will evaluate an AI-generated recommendation and decide what needs to be checked before someone acts on it.

By the end of Module 1, you will be able to:

- Describe the role and responsibilities of an AI-Enhanced Data Practitioner.
- Explain how AI is changing common data science tasks and workflows.
- Identify ways AI can support different stages of data work.
- Explain why organizational, business, stakeholder, and user context matters.
- Recognize situations where AI can help and situations where human expertise is especially important.
- Evaluate AI-generated data, code, analyses, and recommendations.
- Recognize common AI failures and risks.

{% section "Module 2: Framing Data Problems and Understanding Context", "module-2-framing-data-problems-and-understanding-context" %}

Good data work begins **before** you start analyzing a dataset.

Imagine that someone at work tells you, "We need to improve customer service," "We are spending too much money," or "Can you use this data to tell us what is happening?"

Before you ask AI to analyze anything, you need to understand what the real problem is.

In this module, you will practice turning broad organizational questions into clearly defined data problems. You will identify who needs the results, what decision the work needs to support, what success would look like, what data are needed, and what limitations or risks need to be considered.

You will also use AI to help generate questions, challenge assumptions, and explore possible approaches. At the same time, you will practice deciding which questions and decisions require your own judgment.

By the end of Module 2, you will be able to:

- Turn a real-world organizational question into a clearly defined data problem.
- Identify important stakeholders and users.
- Clarify goals, constraints, assumptions, and success criteria.
- Distinguish among data that are **needed, available, and actually usable**.
- Use AI to generate clarifying questions and explore possible approaches.
- Evaluate AI-generated questions, assumptions, and recommendations.
- Identify organizational, user, ethical, and technical issues that may affect the work.
- Decide where AI can help and where human decision-making is required.

{% section "Module 3: Understanding, Exploring, Preparing, Analyzing, and Sharing Data with AI", "module-3-understanding-exploring-preparing-analyzing-and-sharing-data-with-ai" %}

Now you will put the course process into action:

{% figure "data-practice-stages.png", "The five stages: Understand, Explore, Prepare, Analyze, Share." %}

You will work with data much more directly in this module. You will begin by connecting the dataset to the problem you are trying to solve. Then you will explore the data, investigate missing or unusual values, prepare the data for analysis, conduct analyses, create visualizations, and communicate what you find.

AI can support you throughout this process. It can help explain unfamiliar data, suggest questions, generate code, recommend ways to clean data, support analysis, and help create visualizations. But you will not simply accept whatever AI produces. You will test the code, check calculations, investigate unusual results, and decide whether AI's suggestions make sense for the problem you are trying to solve.

By the end of Module 3, you will be able to:

- **Understand:** Explain what a dataset represents and how it connects to a data problem.
- **Explore:** Investigate data quality, distributions, patterns, relationships, missing values, and unusual results.
- **Prepare:** Clean, transform, organize, and document data.
- **Analyze:** Use AI and other data tools to support analysis, coding, calculations, pattern identification, and visualization.
- **Share:** Communicate findings, visualizations, limitations, and important context clearly.
- Check AI-generated code, calculations, analyses, interpretations, and visualizations.
- Identify errors, bias, hallucinations, unsupported conclusions, and other problems in AI-generated work.
- Explain what AI contributed and what knowledge and judgment you needed to contribute.

{% section "Module 4: Communicating Insights, Responsible AI, and Future Trends", "module-4-communicating-insights-responsible-ai-and-future-trends" %}

Finding an answer is not the end of data work. You also need to explain what you found in a way that other people can understand and use. In this module, you will practice communicating data findings through visualizations, summaries, dashboards, presentations, and other forms that may be used in the workplace. You will think about who your audience is, what they need to know, what uncertainty or limitations should be explained, and how to avoid presenting data in a misleading way.

You will also look at some of the larger questions that come with using AI in data work, including **privacy, bias, intellectual property, authenticity, accountability, regulation, and environmental impact**. Finally, you will look ahead at how data jobs are changing. AI tools will continue to evolve, and some of the tools you use today may look very different in a few years. But the skills that help you understand data, solve problems, communicate clearly, think critically, and make responsible decisions will continue to matter.

The course also introduces trends such as agentic AI, greater automation, and the growing expectation that data skills will be used across many different jobs and industries, not only in traditional data analyst roles.

By the end of Module 4, you will be able to:

- Communicate data findings clearly to both technical and nontechnical audiences.
- Use AI to help create and improve visualizations, summaries, dashboards, and presentations.
- Evaluate AI-supported communication for accuracy, clarity, context, and possible misrepresentation.
- Identify responsible AI concerns related to privacy, bias, accountability, authenticity, intellectual property, regulation, and environmental impact.
- Explain how new developments in AI may change data work.
- Describe why documentation, evaluation, data organization, and human oversight become more important as AI automates more tasks.
- Identify areas where you will need to continue building your skills as AI and data work evolve.

{% section "What This Course Will Be Like", "what-this-course-will-be-like" %}

You will not learn AI by simply reading about tools. You will work with **realistic workplace-style problems and data tasks**. At different points, you may encounter:

- messy datasets;
- unclear organizational questions;
- incomplete information;
- AI-generated code that needs to be fixed;
- analyses that need to be checked;
- visualizations that need to be improved; and
- findings that need to be explained to different audiences.

The course is also designed so that what you learn is not tied to one particular AI product. Specific tools will change. The goal is to help you develop ways of working that you can carry into different jobs, industries, and technologies.

The central professional practice throughout the course is simple:

{% callout "highlight" %}
Use AI to help you work faster and more effectively, while using your own knowledge, judgment, and verification to make sure the result is accurate, useful, and responsible.
{% endcallout %}

{% section "About the AI in Community Colleges Initiative", "about-the-ai-in-community-colleges-initiative" %}

This course was developed through the **AI in Community Colleges ([AI in CC](https://aicc.edc.org/))** initiative, led by Education Development Center, Inc. ([EDC](https://edc.org/)) in collaboration with community college partners and supported by the National Science Foundation.

The initiative is focused on helping community college students build the skills they need to understand, use, and contribute to a world in which AI is becoming part of education, work, and everyday life.

Partner colleges include: [Bridgerland Technical College](https://btech.edu/), [Bunker Hill Community College](https://www.bhcc.edu/), [Green River College](https://www.greenriver.edu/index.html), [Harford Community College](https://www.harford.edu/), [Nashville State Community College](https://www.nscc.edu/).
